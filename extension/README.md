# DyslexiForm Browser Extension (v2.1.4)

A real-time typographic accessibility browser extension for Chrome, Edge, Brave, and Chromium-based browsers.

## How to Install in Chrome / Edge / Brave

1. Open your browser and go to:
   - Chrome / Brave: `chrome://extensions`
   - Edge: `edge://extensions`
2. Enable **Developer mode** (toggle switch in the top-right corner).
3. Click the **Load unpacked** button in the top-left corner.
4. Select this directory (`extension` or extracted `dyslexiform-extension` folder).
5. DyslexiForm is now installed! Pin it to your toolbar and click the icon on any website.

## Features
- **Custom Accessible Fonts**: Lexend, OpenDyslexic, Atkinson Hyperlegible, and Comic Sans.
- **Micro-Typographic Tuning**: Font scale, line height, letter spacing, word spacing, and paragraph margins.
- **Bionic Reading Engine**: Real-time fixation anchoring on word syllables.
- **Focus Reading Ruler**: Mouse-following reading guide bar.
- **Visual Comfort Tints**: Soft cream, peach, mint, rose, and inverted dark mode overlays.
- **Instant Live Synchronization**: Updates any webpage without requiring a reload.
